# Site Claude — version 2

## Structure
- `index.html` : accueil et présentation des 3 univers
- `pop.html` : sélection Pop française
- `reggae.html` : sélection Reggae
- `medieval.html` : sélection Médiéval
- `catalogue-complementaire.html` : titres complémentaires
- `catalog.js` : titres, descriptions et chemins des MP3
- `script.js` / `style.css` : fonctionnement et mise en page
- `audio/` : placer ici les fichiers MP3 individuels

## Avant publication
1. Remplacer `VOTRE-EMAIL@EXEMPLE.COM` par l'adresse e-mail réelle dans les 4 pages HTML.
2. Vérifier les mentions de droits et les adapter à la situation réelle avant mise en ligne.
3. Ajouter les MP3 individuels dans `audio/` avec exactement les noms indiqués dans `catalog.js`.
4. Ouvrir `index.html` localement pour vérifier les textes et les liens.

## Important
La page `catalogue-complementaire.html` n'est pas une page protégée. GitHub Pages ne fournit pas, à lui seul, une véritable protection par mot de passe. Elle doit être considérée comme une page accessible par son URL, non comme un espace confidentiel.
